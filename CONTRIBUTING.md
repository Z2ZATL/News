# Contributing

Thank you for improving Z2Zs Lab News.

1. Fork the repository and create a focused branch.
2. Do not commit credentials, personal data, private infrastructure IDs, or
   media without clear redistribution rights.
3. Run the quality gates documented in `README.md`.
4. Open a pull request describing the purpose and verification performed.

By contributing code, documentation, or original interface artwork, you agree
to license it under MIT. By contributing original editorial prose, you agree
to license it under CC BY 4.0. You must have the right to submit every file.

Security issues should be reported privately as described in `SECURITY.md`.
